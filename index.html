Preguntas frecuentes

Todo lo importante antes de empezar.

¿Los invitados deben descargar una app?

No. Ingresan desde el navegador escaneando un código QR.

¿Las fotos aparecen automáticamente?

El contenido puede revisarse y aprobarse antes de ser proyectado.

¿Se personaliza para cada fiesta?

Sí. Podés configurar nombre, logo, colores, fondo y hashtag.

¿Se pueden descargar las fotos y mensajes?

Sí. Todo el contenido proyectado puede descargarse al finalizar para conservarlo como recuerdo único del evento.

¿Qué necesito para usarlo?

Internet, una computadora para moderar y una pantalla o proyector.

¿Sirve solo para DJs?

No. También para salones, organizadores y particulares.
